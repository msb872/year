# 📁 سازنده فولدر سال

ابزاری تحت وب برای ساخت خودکار فولدرهای سالانه بر اساس تقویم شمسی، میلادی و قمری.

این برنامه بدون نیاز به سرور اجرا میشود و اطلاعات کاربر را به هیچ سروری ارسال نمیکند.

---

## ✨ امکانات

- ساخت فولدرهای سالانه
- پشتیبانی از تقویم شمسی
- پشتیبانی از تقویم میلادی
- پشتیبانی از تقویم قمری
- ساخت فولدر جداگانه برای هر ماه
- ساخت فولدر جداگانه برای هر روز
- ساخت دو زیرپوشه برای هر روز:
  - کارهای انجام شده
  - کارهای در دست اقدام
- خروجی گرفتن بهصورت فایل ZIP
- ساخت مستقیم فولدرها روی سیستم کاربر
- رابط کاربری فارسی و راستبهچپ
- تم روشن و تاریک
- نمایش نوار پیشرفت
- اجرای کاملاً محلی در مرورگر

---
